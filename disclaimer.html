05 Analysis Methodology & Limitations

Detection Methodology

AI Citation Scan generates intelligence outputs by analyzing publicly observable technical signals associated with submitted website URLs. The analysis methodology includes:

  • HTTP response header analysis (server headers, X-Powered-By, content security policy, cache-control, and other response metadata)
  • HTML source code pattern matching for CMS signatures, JavaScript library identifiers, analytics pixels, and framework indicators
  • DNS record analysis including A, AAAA, CNAME, MX, TXT, and NS records
  • Public WHOIS registry data for domain registration and nameserver information
  • JavaScript resource URL pattern matching for CDN providers, library versions, and third-party service identifiers
  • SSL/TLS certificate metadata analysis for hosting provider and CDN identification
  • IP range analysis against publicly documented infrastructure provider CIDR blocks
  • Robots.txt and sitemap.xml analysis for CMS and SEO configuration signals
  • Meta tag and structured data markup analysis for CMS and SEO tooling identification

Probabilistic Confidence System

All technology detection results are produced through a weighted fingerprint confidence scoring system. Confidence scores reflect the strength of available evidence, not absolute certainty. A high-confidence detection indicates multiple strong corroborating signals. A low-confidence detection indicates limited or ambiguous evidence. All results should be treated as probabilistic estimates subject to the inherent limitations of public-signal analysis.

06 Public Signals Only — Scope of Analysis

Publicly Observable Layer Only

AI Citation Scan analyzes exclusively the publicly observable technical layer of submitted websites. "Publicly observable" means information that is returned to any standard HTTP client making an unauthenticated request — precisely the same information your web browser receives when it visits a website. This is the same information indexed by search engines, analyzed by security researchers, and visible to any standard HTTP inspection tool.

AI Citation Scan does not and cannot analyze:

  • Content, data, or configurations accessible only behind authentication or login walls
  • Server-side code, databases, or private infrastructure configurations
  • Content Management System administration panels or backend configurations
  • Private API endpoints or internal network services
  • Content protected by IP allowlisting, VPN requirements, or geographic restrictions
  • Dynamic content rendered exclusively through client-side interactions not captured in initial HTTP responses
  • Content protected by bot-detection systems that return alternative responses to automated requests

Implication for Analysis Completeness

Because analysis is limited to the publicly observable layer, results will systematically underrepresent the full technical complexity of analyzed websites. Technologies used only in authenticated areas, server-side only, or protected from public inspection will not appear in analysis outputs. This is a known and unavoidable constraint of the analysis methodology, not an error.

09 Technology Identification Disclaimer

Nature of Technology Detection

Technology identification results produced by AI Citation Scan are derived from pattern matching against publicly observable signals. Detection is inferential — the Platform observes evidence that is consistent with the use of a particular technology, not a direct inspection of the technology itself. This means:

  • False positives are possible: A website may appear to use a technology based on observable signals, when in fact those signals result from a different configuration, legacy deployment, or intentional mimicry
  • False negatives are possible: A website may be using a technology that produces no publicly observable signals detectable by the Platform's analysis methodology
  • Version identification may be approximate: Technology version numbers inferred from public signals may be imprecise, partially obscured, or deliberately modified by website operators
  • Confidence levels are indicators, not guarantees: A "high confidence" detection is more likely to be correct than a "low confidence" detection, but it is not a certainty

No Implied Technical Judgment

The identification of any technology in analysis outputs does not constitute an implicit judgment about that technology's quality, security, suitability, scalability, or appropriateness for any particular use case. Detection is descriptive, not evaluative. Technology choices identified in outputs should be assessed independently by qualified technical professionals in context.
