Conformance Status

The Web Content Accessibility Guidelines (WCAG) defines requirements for designers and developers to improve accessibility for people with disabilities. AI Citation Scan is partially conformant with WCAG 2.1 level AA. Partially conformant means that some parts of the content do not fully conform to the accessibility standard (e.g., third-party directory links).

Technical Specifications

Accessibility of AI Citation Scan relies on the following technologies to work with the particular combination of web browser and any assistive technologies or plugins installed on your computer:

  • HTML / ARIA Landmarks
  • WAI-ARIA (Web Accessibility Initiative - Accessible Rich Internet Applications)
  • CSS Flexbox/Grid for Logical Reading Order
  • JavaScript for Focus Management
