Accessibility Statement

Commitment: WCAG 2.1 Level AA

We maintain high accessibility standards because semantic HTML is not only a human necessity but a core requirement for LLM crawler readability. AI Citation Scan is engineered for screen readers, keyboard navigation, and high-contrast visibility.

  • Full ARIA-labeled navigation for screen readers.
  • Contrast ratios exceeding 4.5:1 for all text elements.
  • Consistent focus-states for non-mouse users.
